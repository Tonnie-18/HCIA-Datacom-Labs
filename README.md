# HCIA-Datacom Practical Networking Labs

A collection of practical networking labs built and tested using **Huawei eNSP** while developing hands-on skills for the **HCIA-Datacom** certification.

The labs focus on common enterprise networking concepts including VLANs, inter-VLAN communication, DHCP, OSPF, WLAN configuration, AAA, and 802.1Q trunking.

## 🛠️ Tools & Technologies

* **Huawei eNSP**
* Huawei network devices and CLI
* IPv4 addressing
* VLANs
* 802.1Q trunking
* VLANIF
* DHCP
* OSPF
* WLAN
* AAA
* Network troubleshooting and verification

## 📚 Labs

### 1. AAA - Authentication, Authorization and Accounting

A practical lab covering **AAA** configuration and network access control concepts using Huawei network devices.

**Key areas:**

* AAA configuration
* Authentication concepts
* User access control
* Huawei CLI configuration and verification

---

### 2. DHCP - Dynamic Host Configuration Protocol

A lab demonstrating the configuration of **DHCP** for automatic IP address assignment within a network.

**Key areas:**

* DHCP configuration
* IP address allocation
* Network connectivity
* Configuration verification

---

### 3. DOT1Q — 802.1Q VLAN Trunking

A lab focused on **802.1Q trunking** and the transmission of VLAN traffic between network devices.

**Key areas:**

* VLAN configuration
* 802.1Q trunking
* Switch configuration
* VLAN connectivity
* Configuration verification

---

### 4. OSPF — Dynamic Routing

A practical lab implementing **OSPF (Open Shortest Path First)** to establish dynamic routing between network devices.

**Key areas:**

* OSPF configuration
* Router interfaces
* Dynamic route advertisement
* Routing-table verification
* Connectivity troubleshooting

---

### 5. VLANIF — Inter-VLAN Communication

A lab demonstrating how **VLANIF interfaces** can be used to enable communication between different VLANs.

**Key areas:**

* VLAN configuration
* VLANIF interfaces
* Inter-VLAN routing
* IP addressing
* Connectivity testing and troubleshooting

---

### 6. WLAN Configuration

A practical lab covering the configuration of a **wireless LAN (WLAN)** environment using Huawei networking equipment.

**Key areas:**

* WLAN configuration
* Wireless network setup
* Network connectivity
* Configuration verification

Through these labs, I have developed practical experience with:
